# Bank Analyzer - Руководство пользователя

## О приложении

Bank Analyzer - система анализа и управления личными финансами, разработанная на Spring Boot. Приложение предоставляет инструменты для учета банковских операций, анализа расходов и контроля финансового состояния.

## Основные возможности

### Управление счетами
- Создание и ведение банковских счетов
- Поддержка мультивалютных операций
- Автоматический расчет балансов
- Привязка банковских карт к счетам

### Учет транзакций
- Регистрация доходов и расходов
- Категоризация операций
- Фильтрация и поиск по датам, суммам, категориям
- Редактирование и удаление операций

### Аналитика и отчетность
- Визуализация финансовых показателей
- Анализ расходов по категориям
- Динамика операций

### Безопасность
- Защищенная аутентификация
- Разграничение прав доступа
